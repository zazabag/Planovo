3. Что уже есть в ядре

## Найдено

- Форма заявки на сайте никуда не отправляет данные автоматически: адрес приёма не задан. Посетитель видит «Заявка принята», а на деле у него только открывается почтовая программа с готовым письмом. Не отправил письмо — заявка потеряна. Нужно чинить в новой версии (например, Telegram-бот, как у Акеды).
- Демо-стенд (проверка кода KEMS, 04.10.2026): одна установка — одно учреждение; гостевого входа нет; сид `seed_demo` заполняет реальными данными КЭМС (ФИО, почты). Под КЭМС зашиты в коде: название и логотип (~67 файлов), сетка звонков в конструкторе, формат кода группы, курсы 1–6 и формы обучения СПО, импорт Excel под файлы КЭМС. Для «Колледжа „Пример“» нужны: сид вымышленного колледжа, вынос названия/логотипа в настройки, сетка конструктора из базы, вход без пароля по ролям с регулярным сбросом. Для школ (классы 1–11) — отдельная переделка формата групп.
- Цифры КЭМС на 04.10.2026: 60 действующих групп, 64 преподавателя, 27 аудиторий, 190 предметов, ~2 800 занятий за сентябрь, 126 выложенных изменений за сентябрь, 2 627 уведомлений за сентябрь, 371 подписанное устройство. Число студентов в базе неполное — не используем.
