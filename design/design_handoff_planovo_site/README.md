# Handoff: сайт planovo.pro — главная страница

## Что это
Дизайн главной страницы сайта Планово (система расписания для колледжей, школ и вузов), собранный по брендбуку и дизайн-киту Планово. Тексты, порядок блоков и обещания — из `content/HANDOFF-claude-design.md` (это источник правды по содержанию; менять смысл и обещания нельзя без согласования с командой).

## О файлах в пакете
Файлы `*.dc.html` — **дизайн-референсы в HTML**, прототипы, показывающие внешний вид и поведение. Это не production-код для копирования. Задача — **воссоздать эти экраны в целевом стеке** (Next.js/React, Astro, Vue или что выберет команда) с его паттернами. Если стека ещё нет — рекомендуем Next.js + CSS-модули или Tailwind с токенами из этого README. Прототипы можно открыть в браузере напрямую (нужен `support.js` рядом).

## Точность
**Hi-fi.** Цвета, шрифты, отступы, радиусы, состояния и анимации — финальные. Воспроизводить точно. Экраны продукта внутри макетов нарисованы на данных выдуманного «Колледжа „Пример“» — реальные скриншоты КЭМС подставит команда (на макете под них оставлены слоты).

## Файлы
- `planovo-site-home.dc.html` — вся главная страница (разметка + логика интерактивов в классе `Component` внизу файла).
- `planovo-role-screen.dc.html` — дочерний компонент «экран роли» (учебная часть / преподаватель / студент / руководство), используется в туре по ролям.
- `ios-frame.jsx` — рамка iPhone (`IOSDevice`, рендерится в 402×874 и масштабируется transform: scale(.7–.72)).
- `image-slot.js` — слоты под изображения (скриншот КЭМС, фото основателей). В проде заменить на `<img>`.
- `uploads/planovo-logo.png` — логотип. Используется как есть: шапка 44 px, первый экран 240 px, уведомление 38 px, подвал 36 px. Перерисовывать нельзя.
- `brand/` — брендбук и дизайн-кит (14 листов + компоненты). Открывать в браузере.
- `content/HANDOFF-claude-design.md` — тексты, структура, правила, контакты.

## Интерактивы и анимации

### Появление при прокрутке
Элементы с `data-reveal`: `opacity 0 → 1`, `translateY(22px) → 0`, 0.8 s, `cubic-bezier(.2,.7,.2,1)`, IntersectionObserver threshold .1.

### Интерактивный конструктор на первом экране
Состояние: `picked` (карточка взята), `hover` (клетка под курсором), `placed {d,s}`, `conflict {d,s}`, `msg`, `published`, `toast`.
- Сетка ИС-21: 4 пары (8:30, 10:10, 12:00, 13:50) × 5 дней. Данные клеток в константе `CELLS` (виды: `lesson`, `free`, `vacated` — отменённая Физика во Вт 10:10, `busy` — Ср 12:00, Петренко занята у ПКС-32).
- Карточка «История · Петренко · ауд. 118» в лотке над сеткой: HTML5 drag-and-drop (`draggable`, `dragstart/dragover/drop`) **и** клик: тап по карточке — взять, тап по клетке — поставить.
- Логика `place(d,s)`: на `lesson` → ошибка «У ИС-21 в это время уже …»; на `busy` → «Петренко в это время ведёт у ПКС-32 в 118. Накладку поставить нельзя»; клетка мигает красным (`plShake` .5 s, рамка `#C44B3B`), сообщение красное 1.5 s. На `free`/`vacated` → карточка встаёт жёлтой «История · Замена», сообщение зелёное «Петренко свободна, аудитория 118 свободна. Накладок нет — можно публиковать», кнопка «Опубликовать» становится тёмной и пульсирует (`plPulse` 1.6 s).
- «Опубликовать» → бейдж «Черновик» → «Опубликовано» (точка зелёная), кнопка зелёная «Опубликовано ✓», тост под макетом 4.2 s, на iPhone студента сверху въезжает уведомление (0.6 s) и строка 10:10 перекрашивается в жёлтую «История · Петренко · 118 · Замена». Ссылка «Сбросить и попробовать ещё».
- Автосценарий: если посетитель ничего не трогал 3.5 s — демо играет само (взять 0 s → навести 1.1 s → поставить 2.0 s → опубликовать 3.4 s → сброс 8.6 s → повтор 10.4 s) до первого касания пользователя.

### Тур по ролям
IntersectionObserver на блоках `data-role-block` с `rootMargin: -45% 0 -45%` (на узких — `-55% 0 -30%`); активный индекс → ключ роли `uch | prep | stud | ruk` → sticky-экран меняется с анимацией появления .6 s.

### Конструктор (4 шага)
Тот же механизм на `data-cstep`. Состояния макета: 0 — черновик (подпись про опубликованную версию от 11 апреля); 1 — чип даты «Вт, 15 апреля» тёмный, клетка Вт 10:10 жёлтая «История · Замена»; 2 — чип «Нечётная неделя» тёмный, появляется чип «Практика с 21 апреля», клетка Ср 12:00 делится на две подгруппы (рамка сливовая); 3 — справа выезжает панель «История изменений» (`translateX(104%) → 0`, .55 s). Неактивные шаги текста `opacity .38`.

### Под ваш бренд
Темы — объект `THEMES` (primer / vesna / noch) + custom: акцент = выбранный цвет, фон `color-mix(in srgb, цвет 7%, #fff)`, линии `color-mix(… 25%)`. Переходы цвета .45 s. Тема «Ночь» переключает статус-бар iPhone в светлый (`dark`).

### Счётчики КЭМС
При появлении блока (threshold .3) значения растут от 0 за 1.4 s, easing `1 − (1 − x)³`; тысячи с пробелом (`toLocaleString('ru-RU')`).

### Прочее
Hover карточек: `translateY(-4px)` + тень, .3 s. Кнопки: тёмная → `#3A352F`, контурная → фон `#E8E1D6`. Плавная прокрутка по якорям (`scroll-behavior: smooth`). Шевроны аккордеона поворачиваются на 180°.
